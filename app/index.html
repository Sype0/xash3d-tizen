Samsung Tizen TV
📱 Send the game data from your phone
Scan the QR code with your phone and pick valve.zip.
Both must be on the same Wi-Fi network.

The game data is not included; you need the valve folder of your own Half-Life copy. Once sent, it is kept on the TV.

Send the game data first

Zip the valve folder of your own Half-Life copy, then:

From a phone: scan the QR code at the top right and pick the zip (TizenBrew only).

Over the network: run python3 serve.py Half-Life-folder on the device that has the files and enter the address it prints.

Game data address

The address printed by tools/serve.py. Example: http://192.168.1.20:8000/
If it does not end in .zip, valve.zip in that folder is downloaded.
